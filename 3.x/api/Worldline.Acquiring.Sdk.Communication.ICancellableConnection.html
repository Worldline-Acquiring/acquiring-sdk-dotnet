    Syntax
    public interface ICancellableConnection : IConnection, IDisposable, ILoggingCapable, IObfuscationCapable
    Remarks

    The communicator uses this interface when the connection implements it, and otherwise falls back to IConnection, in which case a cancellation token is only honoured before the request is sent. A cancellation token that is cancelled after the response has arrived must not discard that response. The response handlers of this interface return a Task<TResult>, so they can await while the response is still open. There are no overloads with a synchronous response handler and a token, because those would make calls with a lambda ambiguous.
